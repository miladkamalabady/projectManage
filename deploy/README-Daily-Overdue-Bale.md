# اجرای خودکار روزانهٔ هشدارهای بله

این کار از طریق API سامانه اجرا می‌شود؛ کاربر لازم نیست وارد سامانه شود. اسکریپت در زمان‌بند ویندوز از API می‌خواهد وظایف عقب‌افتاده را پیدا کند و اعلان‌ها را در صف بله قرار دهد. هر گیرنده در هر روز فقط یک بار اعلان زمان‌بندی‌شده می‌گیرد. ارسال واقعی صف را سرویس پس‌زمینهٔ API انجام می‌دهد.

## راه‌اندازی

1. شاخهٔ `vezarati` را دریافت و API را دوباره روی IIS منتشر کنید. فایل‌های جدید در پوشهٔ `deploy` هستند.
2. یک کلید تصادفی قوی بسازید. در PowerShell اجرا کنید:

   ```powershell
   $rng = [Security.Cryptography.RandomNumberGenerator]::Create()
   $bytes = New-Object byte[] 48
   $rng.GetBytes($bytes)
   [Convert]::ToBase64String($bytes)
   ```

3. کلید را فقط روی سرور وارد تنظیمات API کنید:

   ```json
   "ScheduledJobs": {
     "OverdueBaleApiKey": "کلید تصادفی تولیدشده"
   }
   ```

   پس از ذخیره، Application Pool مربوط به API را در IIS بازیافت کنید. این کلید را در Git یا فایل نمونه ثبت نکنید.

4. سه فایل `Run-Daily-Overdue-Bale.ps1`، `Install-Daily-Overdue-Bale.ps1` و `OverdueBaleJob.example.json` را در یک پوشه روی سرور قرار دهید. از فایل نمونه یک کپی با نام `OverdueBaleJob.json` بسازید. همان کلید را در `ApiKey` و نشانی محلی سامانه را در `ApiUrl` بگذارید. مقدار پیش‌فرض برای فرانت شما:

   ```json
   "ApiUrl": "http://127.0.0.1:4000/api/jobs/daily-overdue-bale"
   ```

   اگر سایت روی نشانی یا پورت دیگری است، فقط همین مقدار را تغییر دهید. فایل `OverdueBaleJob.json` را فقط برای Administrator و حساب SYSTEM قابل‌خواندن نگه دارید.

5. ابتدا بدون ارسال پیام، اتصال و تعداد موارد را آزمایش کنید:

   ```powershell
   .\Run-Daily-Overdue-Bale.ps1 -RunOnce -DryRun
   ```

   این حالت هیچ اعلان یا پیام بله‌ای ثبت نمی‌کند. برای ارسال واقعی فوری، `-DryRun` را بردارید؛ در غیر این صورت اسکریپت هر روز در ساعت تنظیم‌شده اجرا می‌شود.

6. PowerShell را با دسترسی Administrator باز کنید و زمان‌بند را نصب کنید:

   ```powershell
   .\Install-Daily-Overdue-Bale.ps1
   ```

   زمان اجرا با `RunHour` در فایل تنظیمات تعیین می‌شود (۰ تا ۲۳، به وقت محلی ویندوز). زمان‌بند بعد از راه‌اندازی ویندوز خودکار شروع می‌شود و اگر API موقتاً در دسترس نباشد، هر `RetryMinutes` دقیقه دوباره تلاش می‌کند.

## پیگیری نتیجه

گزارش اجرا در مسیر زیر نوشته می‌شود:

```text
C:\ProgramData\Vezarati\Logs\daily-overdue-bale.log
```

ارسال بله باید در تنظیمات ادمین سامانه فعال باشد و موبایل کاربران در پروفایلشان ثبت شده باشد. برای هر روز، وظایف انجام‌شده، لغوشده و ردشده از یادآوری حذف می‌شوند.
