# انتقال دیتابیس پیگیری مصوبات به SQL Server

## پیش‌نیازها

- SQL Server روی سرور اجرا باشد و نمونهٔ `MSSQLSERVER2022` از همین سیستم قابل دسترسی باشد.
- برنامه با فایل تنظیمات فعلی یک بار به SQL Server وصل شود تا دیتابیس و جدول‌های خالی را ایجاد کند.
- فایل پایگاه‌دادهٔ قبلی SQLite (معمولاً `src/Vezarati.Api/data/vezarati.db`) را نگه دارید. پیش از کپی آن، API قدیمی را متوقف کنید.
- اگر پیوست دارید، پوشهٔ `src/Vezarati.Api/data/uploads` را هم جداگانه نگه دارید؛ محتوای فایل‌ها در SQLite ذخیره نشده است.

## ساخت فایل ورود داده

از ریشهٔ مخزن در PowerShell اجرا کنید:

```powershell
py tools\sqlite_to_sqlserver.py "C:\path\to\vezarati.db" -o "C:\path\to\ImportVezaratiToSqlServer.sql" --replace-target
```

فایل SQL تولیدشده را در SSMS باز کنید و روی دیتابیس `vezarati` اجرا کنید. اسکریپت جدول‌های برنامه را از داده‌های SQLite پر می‌کند و شناسه‌ها را حفظ می‌کند.

> این اسکریپت داده‌های جدول‌های متناظر در دیتابیس مقصد را پاک و با داده‌های SQLite جایگزین می‌کند؛ آن را فقط روی دیتابیس مقصد تازه یا قابل بازنویسی اجرا کنید.

## راه‌اندازی برنامه

رشتهٔ اتصال در `src/Vezarati.Api/appsettings.json` روی `DefaultConnection` تنظیم شده است. برای اجرای API:

```powershell
dotnet run --project src\Vezarati.Api
```

پس از انتقال، در صورت وجود پیوست، فایل‌های پوشهٔ قدیمی `data\uploads` را به همان مسیر نسبی کنار API جدید کپی کنید. فایل‌های پیوست به‌تنهایی با انتقال ردیف‌های دیتابیس منتقل نمی‌شوند.
