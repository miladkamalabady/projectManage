# نسخه PHP سامانه مدیریت پروژه سمپاد

نسخه مستقل و سازگار با cPanel برای مدیریت چند پروژه؛ پروژه اولیه سمپاد با ۱۵۹ فعالیت استخراج‌شده از صفحات ۶ تا ۱۶ RFP نصب می‌شود.

## امکانات

- داشبورد پیشرفت و فعالیت‌های نیازمند توجه
- فهرست ۱۵۹ فعالیت با جست‌وجو و فیلتر
- تعریف پروژه‌های جدید و جابه‌جایی بین پروژه‌های مجاز
- افزودن و حذف فعالیت‌های هر پروژه توسط مدیر همان پروژه
- عضویت و سطح دسترسی مستقل کاربران در هر پروژه
- ثبت وضعیت، درصد پیشرفت، یادداشت و ددلاین پیمانکار
- تأیید یا رد مستقل توسط ناظر و بهره‌بردار
- ثبت و پیگیری اشکالات و اقدامات اصلاحی
- ثبت جلسات، مصوبات و اقدامات
- کاربران با نقش مدیر پروژه، پیمانکار، ناظر، بهره‌بردار و مشاهده‌گر
- ثبت تاریخچه تغییرات مهم
- رابط فارسی، راست‌چین و واکنش‌گرا

## پیش‌نیاز

- PHP 8.1 یا جدیدتر
- افزونه‌های PDO MySQL، JSON و mbstring
- MySQL 5.7+ یا MariaDB 10.4+
- Apache و cPanel
- گواهی HTTPS برای دامنه

## نصب روی cPanel

1. در cPanel از بخش **MySQL Databases** یک دیتابیس و یک کاربر بسازید.
2. کاربر را با دسترسی **ALL PRIVILEGES** به دیتابیس متصل کنید.
3. محتویات این شاخه را در پوشه دامنه، معمولاً `public_html`، آپلود کنید.
4. فایل `config.example.php` را با نام `config.php` کپی کنید.
5. نام دیتابیس، نام کاربر و رمز MySQL را در `config.php` وارد کنید. cPanel معمولاً پیشوند حساب را به نام دیتابیس و کاربر اضافه می‌کند.
6. در مرورگر آدرس `https://YOUR-DOMAIN/install.php` را باز کنید.
7. نام، ایمیل و رمز مدیر پروژه را وارد کنید. نصب‌کننده جدول‌ها و ۱۵۹ فعالیت را ایجاد می‌کند.
8. بعد از نصب موفق، فایل `install.php` را از هاست حذف کنید.
9. از `index.php` وارد سامانه شوید و حساب‌های پیمانکار، ناظر و بهره‌بردار را بسازید.

## ارتقای نسخه نصب‌شده

اگر نسخه قبلی سامانه هم‌اکنون روی cPanel نصب است، `install.php` را دوباره اجرا نکنید:

1. از دیتابیس نسخه پشتیبان بگیرید و فایل‌های نسخه جدید را روی هاست جایگزین کنید.
2. با حساب مدیر وارد سامانه شوید.
3. یک‌بار آدرس `https://YOUR-DOMAIN/migrate_v2.php` را باز کنید و دکمه ارتقا را بزنید.
4. فعالیت‌ها، اشکالات، جلسات و کاربران قبلی به پروژه پیش‌فرض «سامانه جامع سمپاد» متصل می‌شوند.
5. پس از پیام موفقیت، فایل `migrate_v2.php` را از هاست حذف و صفحه سامانه را با `Ctrl+F5` تازه‌سازی کنید.

## مدل دسترسی پروژه‌ها

- **مدیر پروژه:** تنظیم مشخصات پروژه، افزودن/حذف فعالیت و مدیریت اعضا
- **ویرایشگر:** ثبت وضعیت، اشکال، جلسه و عملیات مجاز بر اساس نقش سازمانی
- **مشاهده‌گر:** مشاهده اطلاعات همان پروژه بدون امکان تغییر

هر کاربر فقط پروژه‌هایی را در فهرست انتخاب پروژه می‌بیند که در آن‌ها عضو شده باشد. نقش سازمانی (پیمانکار، ناظر و بهره‌بردار) از دسترسی او در هر پروژه مستقل است.

## امنیت

- فایل واقعی `config.php` را در Git ثبت نکنید.
- حتماً HTTPS را فعال و برای حساب‌های کاربران رمز قوی انتخاب کنید.
- از دیتابیس cPanel به‌صورت زمان‌بندی‌شده نسخه پشتیبان تهیه کنید.
- پوشه‌ها و فایل‌های حساس با `.htaccess` از دسترسی مستقیم محافظت می‌شوند.

## توسعه محلی

نسخه PHP برای اجرا به Node.js یا Build نیاز ندارد. پس از تنظیم `config.php` می‌توانید از وب‌سرور داخلی PHP استفاده کنید:

```bash
php -S 127.0.0.1:8080
```

برای استفاده واقعی، اجرای Apache/cPanel توصیه می‌شود.
